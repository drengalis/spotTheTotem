First release of **Spot the Totem**, a WoW Forever addon that puts each totem's spell icon on its nameplate so totems are easy to see.

### Features
- Spell icon on every shaman totem's nameplate (red border for enemy, green for friendly)
- Countdown timer on each icon: white, then yellow under 10 seconds, red under 5
- Separate enemy and friendly settings: spotting on/off, minion nameplates on/off, icon size, and "Only spot selected totems" with a per-totem checklist
- Separate horizontal and vertical icon offsets for enemy and friendly totems
- Option to hide the totem's health bar so only the icon shows
- Minimap button and `/stt` slash commands

### Install
Download **SpotTheTotem-v1.0.0.zip** and extract it into `World of Warcraft\_forever_\Interface\AddOns`, so you end up with `AddOns\SpotTheTotem\SpotTheTotem.toc`.

### Notes
- Minion nameplates must be on for icons to show. Use the checkboxes in the addon's settings or the game's nameplate options.
- Friendly totem icons don't show inside dungeons and raids, because addons can't change friendly nameplates there.
