Bug fix release for **Spot the Totem**.

### Fixed
- **Error flood in instances.** During a boss encounter, in some combat, and on certain maps, WoW Forever hides some unit information from addons as "secret values". The addon tried to read those values on every nameplate, which caused a stream of Lua errors, most noticeably after dying mid-encounter. It now checks for secret values and skips those nameplates quietly.
- **Icons catch up after restrictions end.** When an addon restriction lifts, every nameplate is checked again, so totems that appeared during it get their icons.
- **Error guard.** If anything else unexpected goes wrong, the addon prints one message in chat instead of repeating the error.

### Known limitations
- While a restriction is active, newly placed totems can't be identified and get no icon until it ends. Icons already showing stay up.
- Friendly totem icons don't show inside dungeons and raids, because addons can't change friendly nameplates there.

### Install
Download **SpotTheTotem-v1.0.1.zip** and extract it into `World of Warcraft\_forever_\Interface\AddOns`, replacing the existing `SpotTheTotem` folder.
